# Intimate Log

Приватный self-hosted дневник половых партнёров (18+): карточки с фото, оценки по 10 критериям, пикантные флаги, каталог и лидерборд.

## Возможности

- **Карточка партнёра**: имя, прозвище, возраст (18+), дата знакомства, сколько раз, описание, фото.
- **Оценка по 10 критериям** (1–10, любой можно пропустить) со взвешенным итоговым баллом и тиром S/A/B/C/D.
- **Флаги**: 20 предустановленных (пикантные, green, red, нейтральные) + свои, прямо из формы карточки или на странице «Флаги».
- **Лидерборд**: подиум топ-3, общая таблица, лучшие по каждому критерию, статистика.
- **Каталог**: поиск, фильтр по флагу, сортировка (новые, по баллу, по имени, по количеству раз).
- **Экспорт** всех своих данных в JSON.

### Критерии и веса

| Критерий | Вес | Что оцениваем |
|---|---|---|
| Химия | 1.5 | Насколько «искрило» между вами |
| Страсть | 1.3 | Энергия, желание, вовлечённость |
| Внимательность | 1.3 | Забота о твоём удовольствии |
| Техника | 1.2 | Умения, ритм |
| Комфорт и общение | 1.2 | Легко ли говорить о желаниях и границах |
| Поцелуи | 1.0 | |
| Фантазия | 1.0 | Открытость к экспериментам |
| Привлекательность | 1.0 | Внешность, запах, голос |
| Выносливость | 0.9 | Темп и продолжительность |
| После | 0.8 | Объятия, атмосфера после |

Итог = взвешенное среднее по заполненным критериям. Тиры: S ≥ 9, A ≥ 8, B ≥ 6.5, C ≥ 5, D < 5. Критерии и веса меняются в `app/scoring.py`.

## Приватность

- Каждый аккаунт видит только свои карточки, флаги и фото (проверено тестами).
- Фото отдаются только через авторизованный эндпоинт, без публичной статики.
- При загрузке из фото удаляются EXIF и геометки, изображение ужимается до 1600 px.
- Пароли: PBKDF2-SHA256, 390k итераций. CSRF-токены на всех формах. `noindex` для поисковиков.
- В `docker-compose.yml` порт привязан к `127.0.0.1` — наружу выставляй через reverse proxy с HTTPS или через VPN.

## Запуск в Docker

```bash
cp .env.example .env
# впиши SECRET_KEY: python -c "import secrets;print(secrets.token_urlsafe(48))"
docker compose up -d --build
```

Открой http://127.0.0.1:8000, зарегистрируйся, затем поставь `ALLOW_REGISTRATION=false` в `.env` и `docker compose up -d`. Данные (SQLite + фото) лежат в `./data` — его и бэкапь.

## Локальная разработка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn app.main:app --reload
pytest -v
```

## Стек

FastAPI, SQLAlchemy 2 + SQLite, Jinja2 (серверный рендер, без JS-фреймворков), Pillow. CI в GitHub Actions: pytest + сборка Docker-образа и smoke-тест контейнера.

## Структура

```
app/
  main.py        маршруты (auth, партнёры, каталог, лидерборд, флаги, экспорт)
  db.py          модели
  scoring.py     критерии, веса, предустановленные флаги
  images.py      обработка фото
  security.py    пароли, CSRF
  templates/     HTML
  static/        CSS
tests/           pytest
```

Используй только в личных целях и уважай приватность других людей: не публикуй чужие данные и фото без согласия.
